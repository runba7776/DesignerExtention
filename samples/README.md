# 動作確認用の入力

`comparison.csv` は架空のデータです。企業の実績を表していません。

Claudeを設定した後の入力例:

「この3つの方法を比較し、どのような違いがあるかを日本語で説明してください。高校生向けの5分間の発表で使います。表紙を含め5枚以内。点数の変化から原因までは断定しないでください。」

資料を使わない入力例:

「1からnまでの足し算を、並べ替えた図で説明して数学の面白さを伝えたい。高校生向けに5分間、表紙を含め5枚程度で作成してください。数式と具体例の対応が分かるようにしてください。」

これらはテスト入力例であり、対応できる用途を制限するものではありません。サンプル体験モードでは固定の操作説明資料を生成するため、この指示やファイルの内容を分析しません。

`generated` には、このPCのPowerPointで作成した6枚の出力例を保存しています。データは架空で、AIは使用していません。SmartArt、グラフ、テキストをPowerPointで編集して試せます。A案とB案は同じ内容の配色違いです。
