# 構図カタログ

120種類。2026年10月1日に公開テンプレートを調査し、一般的な配置パターンを独自の編集可能な図形で実装しました。外部のPPTXや画像素材は同梱していません。

## 1. 表紙（cover）

- 分類: 表紙
- 配置: 題名を中央または左上の広い領域に、導入を下に置く
- 用途: 題名と導入を大きく見せる表紙
- 避ける条件: 本文のページには使用しない
- 文字量: 項目名12文字、説明36文字を目安にする。枠の実測を優先する。
- 項目上限: 3
- 調査参考: 既存の構図

## 2. 主張と根拠（evidence）

- 分類: 要点・まとめ
- 配置: 左の主張・図表に約2/3、右の根拠に約1/3を使う
- 用途: 図表の横に短い読み取り。長い表はtable_fullを使う
- 避ける条件: 順序・因果・優劣を配置だけで付けない
- 文字量: 右欄の項目名8文字、説明18文字以内。表は短い数値中心。
- 項目上限: 3
- 調査参考: 既存の構図

## 3. 比較（comparison）

- 分類: 比較
- 配置: 対象を等幅の縦列に並べ、同じ高さで比較する
- 用途: 同じ基準で2〜3の対象を比較する
- 避ける条件: 比較条件が違う対象は条件を明記する
- 文字量: 項目名18文字、説明70文字以内。
- 項目上限: 3
- 調査参考: 既存の構図

## 4. 手順（process）

- 分類: 工程・順序
- 配置: 横向きのSmartArt工程図と、下部の補足
- 用途: 3〜5段階の工程や説明の順序
- 避ける条件: 順序のない項目には使わない
- 文字量: 項目名8文字、説明8文字以内。本文40文字。
- 項目上限: 5
- 調査参考: 既存の構図

## 5. 構造（hierarchy）

- 分類: 親子関係
- 配置: 親から子へ広がるSmartArt階層図を中央に置く
- 用途: 分類や全体と部分の関係を示す
- 避ける条件: 親子関係を変えない。全項目を同じ階層に平坦化しない
- 文字量: 項目名8文字。詳しい説明はノート。
- 項目上限: 7
- 調査参考: 既存の構図

## 6. 循環（cycle）

- 項目上限: 5
