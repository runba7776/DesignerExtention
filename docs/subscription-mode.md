# 月額版との連携・お気に入り・履歴（v0.10.0）

## ChatGPT・Claudeで作る

1. 設定で「月額版で自動作成」を選び、ChatGPTまたはClaudeの公式接続を開始します。初回ログインだけ各社の公式ブラウザー認証を使います。APIキーを登録する必要はありません。
2. 接続したAIと資料・指示を確認し、クラウドへの送信に同意します。抽出された資料本文や数値、指示を各社のクラウドへ送ることに同意した場合だけ処理します。
3. 資料と指示を入力し、「構成を考える」を押します。構成への質問・修正、本文生成、ページ修正は作成画面から続けられます。毎回プロンプトをコピーして別のチャットへ貼り付ける必要はありません。
4. 構成案を確認して「この構成で作成」を押します。発表用は6枚、読む資料用は4枚ずつ分割し、検証済みのページを保持して次のページを依頼します。
5. 文字が収まらない箇所は、情報や数値を保った要約・広い構図を使って調整します。出典や数値の条件を保てない場合は自動で省略せず、画面に修正内容を示します。
6. サムネイルを確認し、書き出します。作成の修正は対象ページを選び、指示を入力して画面から続けます。

ChatGPTは公式の「Sign in with ChatGPT」利用許可と対象アカウントが必要です。利用資格はプラン、アカウント、組織ポリシーにより異なり、接続できない場合があります。ChatGPTプランの利用枠は他の対応アプリと共有されます。[公式の利用条件](https://developers.openai.com/siwc/token-sharing-open-source)

Claude接続では、各利用者のPCにある未改変の公式Claude Codeを使用し、公式の認証・契約上限に従います。APIキーやConsole経由への切替は行いません。公式CLIは初回起動時に必要な依存物を取得する場合があります。Claude利用枠の設定に応じて追加利用料が生じることがあり、Team・Enterpriseは会社の契約と管理者設定を確認してください。[接続方法と利用上の条件](subscription-login-claude.md)

両方とも月額契約だけで無条件に使用できるとは限りません。接続画面に表示される利用許可・上限が適用されます。APIキーを使う従量APIへのフォールバックはありません。処理を画面から行っても、資料や指示が各AI提供者のクラウドに送られます。**月額版連携はオフラインではありません。**

## AIチャットへ手動で渡す

設定で「AIチャット手動連携」を選ぶと、従来どおり指示をコピーし、契約中のAIで実行して、返答を作成画面へ貼り付けるかファイルから読み込めます。ログインの取得や自動送信は行いません。長い指示は「TXTで保存」し、AI側へ添付してください。

この方式もAIが作った完成PPTXの見た目をそのまま移すものではありません。構成・文章・図表データを取り込み、アドインの登録済みの構図・テーマで編集可能なPPTXにします。

## 返答の不備と中断

形式・対象ID・枚数・出典・引用・文字量の不備は、完成済みの資料を変更せず検出します。理由を表示し、修正用の指示を自動で作り直します。もう一度AIに渡し、返答を置き換えてください。アドインが外部モデルを呼ぶ修復処理はありません。

各指示には依頼IDがあります。古い指示への返答を別の段階へ誤って取り込むことを防ぎます。「連携を取り消す」では完成済み資料を保持します。未完了のAI指示・途中の本文はサーバーを再起動すると消えるため、再起動前に指示と返答を保存してください。

同じ画面を再読み込みした場合は、サーバーが起動中なら連携待ち・検証済みページから再開できます。ブラウザーには作業IDだけを保持し、指示・返答・資料本文は保存しません。まだ貼り付けていない返答は、AIのチャット側から取り込んでください。

## Claude Desktopで直接つなぐ（任意）

Claude DesktopのローカルMCP機能を使うと、コピー操作を減らせます。アドインの月額チャット作業の指示をClaudeが取得し、返答をアドインへ返します。アドインから有料APIを呼ぶことはありませんが、Claudeの利用枠を消費します。

1. アドインを起動し、設定でClaudeを選びます。
2. 設定内の「Claude Desktopで直接連携」から接続設定JSONを保存します。固定PC用の例はルートのClaude-Desktop-Connector.example.jsonです。
3. Claude Desktopの開発者設定からローカルMCP設定を開き、保存したJSONのmcpServers内のdesigner-extensionを既存設定へ追加します。既存の接続設定を丸ごと置き換えないでください。企業端末では管理者による制限が適用される場合があります。
4. Claude Desktopを再起動し、designer-extensionのツールが表示されることを確認します。設定画面やローカル拡張機能の位置はアプリ版によって異なります。[公式の導入説明](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop)を参照してください。
5. アドインで「構成を考える」「この構成で作成」「修正する」のいずれかを押します。
6. Claudeへ「Designer Extentionの現在の作業を取得して指示に従い、返答を取り込んでください」と依頼します。必要に応じてツール利用を許可します。
7. 構成承認や次の作業の開始はアドイン画面で行います。複数の作業がある場合はdesigner_list_tasksで作業IDを確認してください。

返答を取り込むと、待機しているアドイン画面にも自動で反映されます。分割作成の場合は次の対象ページの指示へ進みます。

利用するツールはdesigner_list_tasks、designer_get_task、designer_submit_reply、designer_list_designsです。任意のファイル読み書き・外部サービスの呼び出し・勝手な新規作業の開始は提供しません。起動情報は同じPCのサーバーから読み、設定JSONやツール返答へ認証トークンを含めません。ローカルLLMの作業はツールへ公開しません。

MCPが使えない環境やその他のAIでは、上記のAIチャット手動連携を使ってください。利用者の実アカウントでの接続・モデル生成は、この開発検証では実行していません。通信・指示取得・返答取り込みは模擬データで検証します。

## 気に入ったデザインを使い続ける

完成した案の「デザインを保存」、または選んだページから保存します。保存時に1票を記録し、デザイン一覧で追加投票や取り消しができます。同じ配色・書体・構図の組み合わせは統合して票を加算します。

「今の資料に適用」は現在の文章・数字・出典を保持し、適合する構図だけを変更します。「次の作成で使う」は新しい作成の参考にします。未指定時も同じ表示モードの投票が多いデザインを参考にします。保存名は表示用で、AIへの指示として渡しません。

投票はローカルな好みの記録で、AIを再学習する機能ではありません。デザイン記録には本文や数値を保存しませんが、プレビュー画像には元のスライド内容が表示される場合があります。

修正で追加するグラフや大きな数値は、元のページ、利用者の指示、または指定した出典に実在する値か確認します。百分率や負数の表記差も扱いますが、単位・期間・計算・因果関係まで証明する検証ではありません。重要な数値は原資料と照合してください。

## 履歴から戻す

完成資料はPCに自動保存されます。「保存した資料」から開く・複製・保存版の確認ができます。最大20件の過去版と現在版を保持し、過去版は新しい履歴へ複製して開きます。現在の資料は上書きしません。

見た目を変えた複数案の比較、履歴を開く、デザインを適用、書き出しはAIを呼び出しません。本文をAIで変える場合だけ、選んだチャットまたはローカルLLMの処理へ進みます。

## 機密性

解析・保存・描画はPC内ですが、指示をチャットに貼り付けたりMCPで取得したりすると、そこに含まれる資料内容をクラウドAIが処理します。月額版連携をオフライン処理とは扱えません。外部に送れない資料はローカルLLMを選んでください。

ChatGPTでの資料作成は[公式の紹介](https://learn.chatgpt.com/use-cases/generate-slide-decks)、Claudeのファイル作成は[公式の説明](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)を参照してください。
