# Designer Extention

資料と指示を読み取り、確認の会話と構成案を経て、編集可能なPowerPointを作成するWindows向け試作アドインです。特定の業界・用途・ゴールは固定していません。

## 更新の反映

作成中の資料を保存してから `Restart-DesignerExtension.cmd` を実行し、開いた画面でAPIキーを入力し直してください。v0.8以降の作成済み資料は「履歴」から再開できます。構成相談中の未保存作業とAPIキーは再起動で消えます。v0.7以前の作業はPowerPointファイルを保存してから更新してください。実行中と画面の版が異なる場合は、操作前に再起動を案内します。

## 起動

1. `Start-DesignerExtension.cmd` をダブルクリックします。
2. 右上の設定を開き、Claude APIキーとモデル名を入力します。枚数（自動または2〜30枚）とテーマ（AIにおまかせまたは12種類）もここで選べます。キーはこのPCで動くサーバーのメモリだけに保持し、再起動すると消えます。
3. 必要ならPDF・CSV・XLSX・PPTX・TXT・MDを追加し、プロンプトを入力します。資料なしでも開始できます。指示は最大60,000文字です。
4. 確認質問に答え、構成案を確認して作成します。
5. サムネイルで内容を確認し、別案の比較、部分修正、PowerPointでの表示を行います。各サムネイルの「構図」から、内容が保たれ文字が収まる配置を選べます。グラフがあるページでは「グラフ」から種類を切り替えられます。構図変更・テーマ変更・書体変更・グラフの種類変更にAI呼び出しは不要です。画面上の「構図一覧」で全種類の配置・用途・文字量を検索できます。

キーを使わず確認する場合は、設定で「サンプル体験」を選びます。このモードは固定の操作説明資料を作成します。入力テーマに沿ったAI生成や資料分析は行いません。

終了するときは `Stop-DesignerExtension.cmd` を実行します。ブラウザーを閉じるだけではサーバーは停止しません。停止するとメモリ内のAPIキーと未保存作業が消えます。作成済み資料は自動保存した「履歴」から開けます。配布・保管するPPTXは「保存」からダウンロードしてください。

## PowerPointのリボンから開く

`Install-PowerPoint-Addin.cmd` を実行すると、現在のWindowsユーザー向けに登録します。PowerPointを次に起動すると「Designer Extention」タブから開けます。開いている資料は保存してから、必要なタイミングでPowerPointを再起動してください。

この初期版は、リボンからPC内のブラウザー画面を開くCOMアドインです。PowerPoint内に常設する作業パネルではありません。画面と資料処理はPC内のサーバーで動き、PowerPoint自身がPPTXとプレビュー画像を生成します。Office.jsの外部配信には依存しません。

登録解除は `Uninstall-PowerPoint-Addin.cmd` を実行します。生成した資料は削除しません。

## できること

- PDFの文字、CSV、XLSXの保存済み値、PPTXの文字・表・SmartArt内の文字・保存済みグラフ数値・発表者ノート、TXT・MDをローカルで読み取る。
- 作成済み資料を会話・根拠資料と一緒にこのPCの履歴へ自動保存。再起動後も開く・複製・編集が可能。開く・複製・テーマ・書体・構図・グラフ形式の変更はAI呼び出しゼロ。内容をAIに修正させる操作は別途呼び出します。
- 長いプロンプトを最大60,000文字まで受け付け、原文を保持。12,000文字を超える会話の条件を構成案と一緒に確認し、承認した条件で生成時の再送量を減らす。
- 読み手や目的が曖昧な場合の確認、構成の承認、スライド単位の修正。
- 日本語、表紙込み最大30枚。発表用／読む資料用。自動枚数または2〜30枚を指定。
- 120種類の図形文法。比較・要約・表・工程・年表・グラフ・数式・原因分析などを複数の配置で表現。各文法に用途、配置、避ける条件、文字量、項目上限を記載。[図入りの構図カタログ](docs/layout-catalog.html)・[文章版](docs/layout-catalog.md)・[有料テンプレートの追加調査](docs/template-research.md)も参照できます。
- 同じ資料内の重複と最近の使用履歴を見て、内容と文字量に合う構図に分散。新規生成ごとに同等候補の優先順位が変わります。順序や親子関係は勝手に変えず、文章・数値・数式・図表を保持します。適合候補が少ない内容では同じ構図になる場合があります。
- 12種類のテーマ。既存6テーマにカラー ブロック／アーカイブ／プリズム／ルミナス／ノート／クラスルームを追加。配色、表紙、見出し、本文の区切りと表のスタイルを切り替える。
- 主張・数値・説明の大きさを分け、IT・学習・科学・環境・医療・製造・物流など、意味を表す48種類の編集可能なアイコンを使用。数値・符号・単位を途中で折り返さず、広い適合構図へ変更。[文字と図形の設計基準](docs/design-principles.md)・[添付版の改善例](docs/design-improvements.html)。
- 7種類の書体の組み合わせ。特徴・用途をAIに渡し、見出し・本文・数値・数式に適した書体を指定。作成前の設定と作成後の書体選択で変更できる。[書体と配色の見本](docs/style-catalog.html)・[Microsoftテンプレートの調査](docs/microsoft-style-research.md)。
- 文章が枠に収まらない場合は、まず広い適合構図へ変更。それでも必要な場合は該当ページをまとめてAIで要約。元の文章はノートに保持。PowerPointでも通常の文字枠とSmartArtの幅・高さを実測し、読みやすい文字サイズの下限で収まらなければ書き出しを止めて調整を案内します。
- 7種類の編集可能なグラフ：横棒・縦棒・折れ線・円・ドーナツ・積み上げ横棒・積み上げ縦棒。数値や割合を表示し、明るい／暗いテーマで区別できる8色を使用。種類を変えても元の数値・単位・出典は保持します。[アイコンとグラフの見本](docs/icons-charts.html)・[使い分けと拡張方法](docs/icons-charts.md)。
- PowerPointのSmartArt、編集可能な図形・テキスト、発表者ノート。
- 実際のPowerPoint出力から作るサムネイルとPPTX。
- 同じ内容でテーマと構図が異なる比較案を、追加のLLM呼び出しなしで作成。
- 評価をPC内に保存し、以後の配色候補の順位に反映。モデルの再学習は行いません。
- Claude APIと、ローカル／社内向けの互換API接続を分離。接続失敗時に外部APIへ自動切り替えしない。

## データと費用

Claudeを選ぶと、指示・会話・抽出した資料内容をAnthropicに送信します。送信前に画面で確認します。API料金はユーザーのAPI契約に発生します。

構成案は見出し・役割・短い要点だけを生成し、本文は構成承認後に作ります。v0.8.3では生成・修正の不備を既定で自動対処します。1回の操作で最大2回、出力上限・返答形式・ページや図表の仕様・出典・文字量を確認して必要な部分だけを再試行します。1作業の合計12呼び出しを超えず、対処内容・実際に修正した箇所・呼び出し回数を画面に表示します。設定からオフにすると自動の有料再試行は行いません。[自動対処の使い方](docs/automatic-repair.md)。

v0.8.1では構成の出力枠を8,000→16,000トークンへ拡張しました。構成の回答枠は16,000トークン、自動対処または手動再開では20,000トークンまで使います。指定の枚数と必須条件は保持します。[出力上限への対処](docs/output-limit.md)。

APIキーをブラウザーのlocalStorageや設定ファイルに保存しません。非機密の接続設定と評価結果は `runtime` に保存します。作成済み資料・会話・抽出した根拠資料は `runtime/presentations`、生成PPTX・プレビュー・描画用データは `runtime/artifacts` に保存します。履歴は暗号化していないローカルのJSONです。機密資料を扱う場合はこれらの保存先も管理してください。履歴には元ファイル本体・APIキー・起動トークン・接続先設定を含めません。

履歴から開いた時点では外部送信しません。現在選択中の処理先を使い、Claudeで初めて修正するときは送信同意を再確認します。「削除」は履歴だけを削除し、元資料・ダウンロード済みPPTX・書き出し済みファイルは削除しません。別の画面で同じ履歴を更新すると、古い内容での上書きを止め、開き直しまたは複製を案内します。

長文の条件整理は構成相談の応答に含め、専用の要約呼び出しを追加しません。モデルが確認用条件を返さなかった場合は警告し、原文をそのまま使います。さらに長い参考本文はTXTやMDなどの資料として追加し、指示欄には目的・優先順位・制約を書いてください。資料は引き続き合計12万文字までで、黙って省略しません。[履歴と長文入力の使い方](docs/history-input.md)。

構図の重複回避には `runtime/layout-history.jsonl` の最近の構図IDだけを使用します。この履歴には資料名・文章・数値・プロンプトを保存しません。構図選択の追加API呼び出しはありません。構成相談では簡潔なカタログ、本文生成では関連する文法の詳しい情報だけを送り、無関係な文法の説明を減らします。

サーバーは127.0.0.1だけで待ち受け、起動時の認証と同一オリジン制限を適用します。ローカルモードでは公開URLを接続先に指定できません。社内接続先はプライベートIPv4アドレスを使用します。PowerPoint本体やWindowsの同期・通信設定はアドインが管理する範囲に含みません。

呼び出し数とトークン数を表示します。無制限な自動再試行は行いません。構成の確認後、本文は発表用6枚、読む資料用4枚までを一度に生成します（30枚なら本文5回／8回）。出力上限で止まった場合は、検証できた完成済みページだけを保持し、残りを小分けに自動対処します。自動対処をオフにした場合や対処後も止まる場合は、画面のボタンで再開できます。文字量の調整は必要なページを4枚までまとめて行い、調整済みの文章も再利用します。1つの作業の合計は12呼び出しまでです。小分けにすると再送する入力が増える場合があるため、常に料金が下がるという保証ではありません。枚数が多いほど出力量・料金も増えます。テーマ変更や見た目だけの別案はAIを呼び出しません。

## 現時点の制約

- スキャン画像だけのPDFの文字認識と、PDF中の画像・グラフの視覚解析は未対応です。
- PDFの表は文字の読み順が変わることがあります。CSV・XLSXの方が数値の対応を確認しやすくなります。
- Excel数式を再計算しません。Excelで計算して保存された結果を使用します。
- PowerPoint入力は参考情報の読み取りです。元のテンプレート・レイアウトの完全再現や、PowerPointで直接編集した内容の履歴への自動同期は行いません。グラフはPPTX内の保存済みキャッシュを読み、欠けた値を推測しません。画像内文字・外部リンク・マクロは処理しません。.pptは.pptxとして保存してください。
- 1ファイル15 MB、8ファイル、抽出量は合計12万文字まで。超過時は黙って切り詰めず、対象を分けるよう案内します。
- AIによる説明・比較・計算結果の正しさを保証するものではありません。出典と実際の資料を照合してください。
- 数式は文字として編集できます。初期版はLaTeXやPowerPointの数式オブジェクトへの変換は行いません。
- ローカルLLMは接続部分を実装していますが、実モデルでの品質・速度・外部通信の検証は別途必要です。
- 長文の条件整理・文章要約・30枚のAI生成は模擬応答での検証です。実際のClaudeでの要約・構成の品質は、ユーザーのAPIキーを入力してから確認してください。
- 現在の別案はテーマと適合する構図を変えます。異なるストーリーの自動比較、独自の会社テンプレート、モデル再学習は後続の拡張対象です。
- 最初の生成は新しいPPTXとして保存します。開いているユーザーの資料を自動で上書きしません。
- アドインは開発用の未署名ビルドです。企業配布にはコード署名や組織の導入手順の整備が必要です。

## 開発と再ビルド

前提: Windows、デスクトップ版PowerPointとExcel（編集可能なグラフの作成に必要）、Node.js 22以降、.NET Framework 4.x。

ネイティブ部分を再ビルドする前に、開いている資料を保存し、PowerPointを終了してください。アドイン読み込み中はDLLを更新できません。

```powershell
npm install
npm run typecheck
npm test
npm run build
npm run build:native
powershell -NoProfile -ExecutionPolicy Bypass -File native/Verify-Interop.ps1 -CheckRegistration
# 実際のPowerPointで30枚×2テーマを生成する任意の検証（AI不使用）
node node_modules/tsx/dist/cli.mjs native/Verify-Rendering.ts --expanded
```

まとめて実行する場合は `Setup-DesignerExtension.ps1` を使用します。`-RegisterAddin` を付けるとリボンへの登録も行います。
