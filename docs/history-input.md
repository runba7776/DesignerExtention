# v0.8：履歴の再利用と長い指示への対応

このページは旧版の検証記録です。v0.10.0の月額版・ローカル連携と保存版は[現在の操作説明](subscription-mode.md)を参照してください。

スライドを作成すると、このPCに内容・会話・抽出した根拠資料を自動保存します。右上の「履歴」で開くか、「複製して編集」で元を残して変更できます。「履歴に保存」から手動でも保存できます。テーマ・書体・構図・グラフ形式の変更、比較案の作成、再書き出しにはAIを呼び出しません。

内容の修正はスライドの鉛筆ボタンから指示します。AIに依頼するので、この操作はモデル呼び出しが発生します。履歴を開いた後の呼び出し数は0から数えます。Claudeでの修正を始めるときは、履歴の指示・根拠資料を外部へ送ることを確認します。

履歴の保存先は `runtime/presentations`、生成したPPTXとサムネイルは `runtime/artifacts` です。APIキー・元ファイル・起動用トークンを履歴には保存しません。履歴は暗号化していないJSONなので、PCと保存先のアクセス管理が必要です。削除は履歴だけが対象で、PPTXや元資料は残ります。最大500件です。

外部でPowerPointファイルを編集しても、その変更がアドインの履歴に自動で戻るわけではありません。編集後のPPTXを参考資料として読み込むことはできます。PPTX入力は文字・表・SmartArt内の文字・保存済みグラフ値・発表者ノートを取り込みます。元の配置やテーマの再現、画像の文字認識、外部データ取得には対応していません。欠けたグラフ値は欠測として保持し、ゼロで補完しません。

指示の上限は12,000文字から60,000文字へ拡張しました。長い指示は構成相談の際に、目的・対象読者・必須条件・指定した数値や期間・禁止事項・未確定事項を整理し、「確認する条件」に表示します。条件に抜けがあれば作成前に同じ入力欄から修正してください。承認後の生成では、確認済みの条件を使い、長い会話の原文を毎回送り直す量を減らします。原文は会話と履歴に保持します。条件整理だけのための追加呼び出しは行いません。条件の要約精度は利用するモデルに依存します。

60,000文字を超える参考本文は、TXTやMD・PDF・PPTXなどの資料欄へ分けて追加し、プロンプトには目的と制約を残す方法が使えます。1件15 MB・8件・抽出量の合計12万文字・PDF/PPTX180ページまでです。さらに大きい資料は対象ページや章を分けてください。この版では長大な資料を自動で分割して検索する機能は未実装です。超過時は途中で切らず、入力全体を拒否して案内します。

API料金なしで検証しています。保存からの再開・数値と根拠の保持・同時編集の上書き防止・送信同意・60,000文字の日本語送信は自動テストで確認済みです。実際のClaudeによる長文の条件整理の品質は今回の検証に含みません。
