# 文字と図形の設計基準

2026年10月1日。添付「Designer-Extention (3).pptx」と [Cone / c-slide の39のデザインパターン](https://cone-c-slide.com/see-sla/blog/design-pattern/) を確認して反映しました。

記事は、情報同士の関係、関係を持たない情報、表紙などページの役割に分けて配置を選ぶ考え方を紹介しています。短い並列項目には円・四角・アイコン、長い説明には縦の一覧、数値には大きさの強弱を使うという公開見本を参考にしました。販売されているファイルや素材は取り込んでいません。

## 人が見て良いと感じるために必要なこと

設計上重視するのは、次の5点です。

1. **最初に読むものを決める。** 1枚の主張を短い見出しや大きな結論として示します。数値が重要なら数値を大きくし、説明と同じ大きさにしません。同格の項目は同じ大きさに保ちます。
2. **配置で関係を説明する。** 独立した要点は同じ大きさの円や枠、比較は同じ位置の項目、工程は番号と矢印を使います。資料にない順位や因果を付けません。
3. **読む負担を減らす。** 見出しと説明を区別し、文字の詰め込みを避けます。桁区切り、符号、金額、単位を途中で切りません。文章は意味を残して要約し、条件・全文・出典をノートに保持します。
4. **視覚上の意味を統一する。** 同じ対象には同じ位置・配色を使います。アイコンは項目名の意味に合うものだけを選び、色に頼らず文字でも識別します。
5. **全体に緩急を付ける。** 大きな結論、根拠の表、工程、まとめを必要に応じて組み合わせます。書体や背景は資料全体でそろえ、配置は内容に合わせて変えます。

## 今回の実装

- 見出しは発表用34pt／読む資料用32ptを基本に、文字量に応じて測定・調整。説明は17〜19pt、項目名は主に24〜26pt、大きな結論は38pt、数値は主に36〜42pt。収まる配置を選んでから、必要な調整をします。
- 円内の要点、アイコン付きの枠・横帯、結論の色面、広い数値枠、比較、工程、数式の10文法を追加。合計118文法。配置・用途・文字量・不向きな条件は共通カタログに登録しています。
- 12種類の意味を表すアイコンを、PowerPointの線・円・四角から作成。書体の絵文字や外部サイトの素材に依存せず、オフラインで描画・編集できます。項目ごとに選択・省略でき、未指定なら項目名に合うアイコンだけを選びます。
- 数値は表示文字列を一行で保持し、幅が足りなければ文字枠の問題として検出。英単語や文章中の符号付き数値も途中で分割しません。PowerPoint側でも数値の自動折り返しを無効にし、実際の文字幅・高さを検査します。
- 自動構図選択で、項目名・数値と説明の大きさの差、図形でまとめられた情報を評価。内容の保持と意味上の互換性、重複の回避を優先します。主張を大きく見せる文法は明示的に選んだ場合だけ使用します。
- 構図の選択・描画には追加のAI呼び出しを使いません。モデルの重みを再学習する処理はなく、生成時の設計指示とローカルの配置規則に反映しています。

## 見本と確認

[添付版との比較](design-improvements.html) と [全構図の一覧](layout-catalog.html) で確認できます。比較用の財務資料は添付PPTXの数値・条件を使い、原文のノートも保持しています。元のPDFを使った財務内容の再検証は別作業です。

実在ロゴの画像の取り込みは今回の機能に含めていません。実装したものは意味を伝える汎用アイコンです。今後ロゴを追加する場合は、ユーザーが指定した画像を縦横比と余白を守って配置する形で拡張できます。

合否は最終的に人の確認で決めます。自動検査では文字枠・重なり・資料の保持を確認できますが、「この相手にこの順番で伝わるか」は使用後の評価で改善していきます。
