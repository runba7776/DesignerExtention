# アイコンとグラフの使い分け（v0.7.0）

48種類のアイコンと7種類のグラフに対応します。アイコンの選択は生成時の指示と項目名、グラフの選択は数値の関係から判断します。モデルの再学習ではなく、用途を記したカタログを渡す方法です。選ぶための追加API呼び出しはありません。

## アイコン

| 分類 | 対応する内容 |
| --- | --- |
| 仕事・情報 | 発想、資料、分析、人、地域、保護、時間、目標、組織、費用、調査 |
| IT・技術 | PC、スマートフォン、サーバー、データベース、クラウド、ネットワーク、プログラム、AI・半導体 |
| 学習・科学 | 計算、学習、学校、化学実験、物理、幾何、パズル |
| 環境・資源 | 自然、再利用、電力、水、太陽光 |
| 健康・暮らし | 健康、医療、バリアフリー |
| 産業・移動 | 製造、保守、物流、鉄道、航空、小売、製品 |
| 対話・場所 | 対話、メール、撮影、拠点、日付、節目、法務 |

アイコンは独自の通常図形と線で描き、PowerPointで編集できます。外部の画像取得やアイコンフォントに依存しません。色は選択したテーマに合わせます。会社名から実在ロゴや承認マークを作りません。内容に合わない場合は付けず、生成形式の `items.icon:"none"` でも省けます。

「円の中にアイコンと要点」「アイコンと本文を囲む」「アイコンと見出しの横帯」「アイコンと色帯で比べる」「グラフとアイコン付きの読み取り」などの構図で使用します。生成時の指示に「学習・科学のアイコンを添えて」など、伝えたい意味を加えられます。

## グラフ

| 種類 | 向いている情報 | 必要な条件 |
| --- | --- | --- |
| 横棒 | 項目間の量、長い項目名の比較 | 同じ単位・比較条件 |
| 縦棒 | 少数の対象や期間の量 | 棒の基準は0 |
| 折れ線 | 時間に沿う変化 | 意味のある連続した順序 |
| 円・ドーナツ | 全体の内訳の割合 | 非負で合計が正の1系列。内訳に漏れ・重複がない |
| 積み上げ横棒・縦棒 | 対象ごとの合計と内訳 | 非負の2〜3系列。同じ単位で加算できる内訳 |

最大8カテゴリ・3系列。発表用では原則5カテゴリ・2系列を目安にします。別々の指標である売上・利益・資産を円や積み上げで表しません。入力にない数値を図のために作りません。数量のない説明はアイコン・図解・テキストで示します。

グラフはPowerPoint本来のグラフとして保存し、埋め込みExcelから数値を編集できます。棒・折れ線では値、円・ドーナツでは割合を表示します。割合表示は小数第1位への丸めで、元データは変えません。5.5%未満の内訳や狭い図・多数の系列ではラベルを減らして重なりを避けます。項目と元データは保持します。詳しく読む場合は「図を大きく見せるグラフ」を選びます。

新規出力の埋め込みExcelを入力データから直接組み立て、保存後に表示値・セル・グラフの形式・横棒のゼロ基準を照合します。Excelが古い初期データを保存する場合にも入力値を確実に残すためです。既存の利用者のPPTXを書き換える処理には使用しません。

生成後、対象サムネイルの「グラフ」で種類を切り替えます。現在のデータ条件に適合する候補を表示し、用途の説明を添えます。条件・期間・内訳の意味は原資料と照合してください。数値・単位・出典・他のページは変更せず、選択した案のPowerPointとサムネイルだけを再作成します。API追加料金はかかりません。

## 機能を追加する場所

- `shared/icons.ts`：名前・分類・項目名から選ぶ規則・編集可能な図形の定義。
- `shared/charts.ts`：グラフの用途、避ける条件、データ条件、テーマに合わせた色。
- `shared/layouts.ts`：配置と文字量。現在は120文法。
- `native/Renderer.cs`：PowerPointのグラフを作成。`native/ChartIntegrity.cs` が保存後のグラフ形式・値・データを照合。
- `web/ChartDialog.tsx`：種類を変える画面。変更はローカルで処理。

参考にした公式仕様：[Officeのグラフ形式](https://learn.microsoft.com/en-us/office/vba/api/excel.xlcharttype)、[PowerPointのデータラベル](https://learn.microsoft.com/en-us/office/vba/api/PowerPoint.Series.ApplyDataLabels)、[グラフ形式ごとのラベル位置](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/e2b1697c-7adc-463d-9081-3daef72f656f)。
