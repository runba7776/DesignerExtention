# Microsoft テンプレート・書体の調査と実装

2026年9月30日、[Microsoft PowerPoint の公開テンプレート一覧](https://powerpoint.cloud.microsoft/search/templates/)のサムネイルを閲覧しました。
個別テンプレートを開く操作はサインイン画面に移動するため、内部スライドや元のテーマ定義は確認していません。ここに記載する配色と書体は、公開見本からの着想と当アドインの設計判断です。特定テンプレートのフォントを正確に再現したという意味ではありません。

## 配置・配色の参考

| 公開されている見本 | 観察した配置 | 実装への反映 |
| --- | --- | --- |
| カラー ブロックのデザイン | 大きな色面で領域を区切り、濃淡で本文との関係を示す | 等幅の色枠、色付きの見出し、色面付きの本文列 |
| プリズム デザイン | 複数のアクセント色と余白の組み合わせ | 同格の項目に色を割り当て、帯・文字・枠を同じ色にそろえる |
| ノートのデザイン | 黄と黒の対比、見出しと区切り線の強調 | ノートテーマ、番号帯、横長の説明行 |
| アーカイブ デザイン | 控えめな背景、写真や文字の周囲の余白 | 生成りのテーマと明朝の見出し、説明を囲む細い枠 |
| ルミナス デザイン、濃色のモダニスト プレゼンテーション | 明るいアクセント、背景との強い明暗差 | 濃い青の背景、水色・桃色・金の色、本文とのコントラスト |
| 独創的な図形のデザイン、オフセット デザイン | 図形をずらす構成、大きな見出し | 等しい大きさの枠を上下にずらす要点の配置 |

PPTX・画像・フォントのダウンロードや転載は行っていません。図形と配色は独自に実装し、本文・表・グラフの編集を保ちます。追加8構図を含め、文法は108種類です。生成時にテンプレートサイトへ資料を送る処理はありません。

## 書体の特徴を持つ7つの組み合わせ

| 組み合わせ | 見出し | 本文 | 欧文・数値 | 選択の目安 |
| --- | --- | --- | --- | --- |
| 端正なゴシック | Yu Gothic | Yu Gothic Medium | Bahnschrift | 汎用・企画・技術説明。細いウェイトを小さい本文に使わない |
| くっきり読みやすく | Meiryo | Meiryo | Arial | 画面で読む説明。字幅が広いため列に余裕を取る |
| すっきりモダン | Yu Gothic UI | Yu Gothic UI | Segoe UI | 現代的な紹介。本文の文字サイズを保つ |
| 明朝の見出し | Yu Mincho | Yu Gothic Medium | Georgia | 研究・読み物。明朝を細かい表に多用しない |
| 判別しやすい UD | BIZ UDPGothic | BIZ UDPGothic | Arial | 比較・報告・投影。文字の判別と条件の読み取りを重視 |
| 本のような見出し | BIZ UDPMincho Medium | BIZ UDPGothic | Georgia | 講義・文章中心の説明。装飾書体を増やさない |
| 親しみのある教科書体 | UD Digi Kyokasho NP | BIZ UDPGothic | Arial | 数学・授業・身近な話題。教科書体は大きな見出しに使う |

数式には Cambria Math、日本語の単位には本文の日本語フォントを指定します。同じ数値欄でも「100」と「万円」の文字を適切な書体で描画します。フォントの供給・ファミリーの確認には[Microsoft の Windows フォント一覧](https://learn.microsoft.com/en-us/typography/fonts/windows_11_font_list)と[BIZ UDGothic の説明](https://learn.microsoft.com/en-us/typography/font-list/biz-udgothic)を参照しました。

これはモデルの再学習ではありません。AIに渡す書体カタログに特徴・用途・避ける条件を記載し、宣言された候補から選ばせます。AIやユーザーが任意の描画コードや外部フォントを実行する仕組みはありません。

## 表示ルール

- 資料全体でテーマと書体の組み合わせを統一し、見出し・本文・数値・数式の役割を分ける。
- 箇条書きや横の羅列は、色面・枠・帯でまとまりを示す。色は数量・優劣を示すものではない。
- 本文は原則17ポイント以上。途中の省略記号で隠さず、必要なら要約して全文をノートへ残す。
- 色付きの項目名と背景のコントラストを検査し、色帯上では白か濃い文字を選ぶ。色だけに頼らずラベルと位置で区別する。
- 未インストールの書体は、このPCにある書体に置き換えて通知する。外部からフォントを取得しない。
- 作成後のテーマ・書体変更はローカル処理。変更の追加AI呼び出しはない。実際のPowerPointの文字枠を測定し、収まらない出力を止める。
